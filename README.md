🏠 Real Estate Insights Dashboard — Tableau

📊 Project Overview

An interactive Real Estate Sales Insights Dashboard developed using Tableau to analyze property sales, sales trends, property types, residential categories, and geographical sales performance.

🎯 Objectives

- Analyze total real estate sales
- Compare yearly sales trends
- Understand property type distribution
- Analyze sales by town/location
- Compare residential property categories
- Identify regional and time-based sales patterns

🛠️ Tools & Technologies

- Tableau Public
- Tableau Desktop
- Data Visualization
- Data Analysis
- GitHub

📈 Dashboard Features

- Total Sales KPI
- Total Properties KPI
- Average Sales Amount KPI
- Year-over-Year Sales Trend
- Property Type Distribution
- Total Sales by Town
- Sales by Location Map
- Sales Volume by Residential Type
- Average Sales Ratio Highlight Table
- Interactive Property Type Filter
- Regional & Time Analysis

🔍 Key Insights

- Real estate sales vary significantly across different towns.
- Yearly sales trends show changes in overall market performance.
- Property types contribute differently to total sales.
- Geographic analysis helps identify high-performing locations.
- Residential property categories provide additional insights into sales volume.
